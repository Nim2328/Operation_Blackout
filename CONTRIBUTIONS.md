# Operation Blackout – Individual Contributions

## Project Overview

Operation Blackout is an incident-response themed CTF platform developed
for the IE3132 Penetration Testing assignment. The project contains eight
investigation stages covering OSINT, steganography, cryptography, web
security, network analysis, memory forensics, Linux privilege escalation,
and reverse engineering.
