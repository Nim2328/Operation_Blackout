Each input byte is transformed using XOR with:

    0x13

    transformed[i] = input[i] XOR 0x13

    5d 56 5a 5f 5a 5f 7e 7b 7a 5d 5e 59 7b 7f 7e

Because XOR is reversible, the original input can be recovered by
applying XOR 0x13 to each byte.
